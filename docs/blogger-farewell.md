# Farewell post for the old blog (draft)

To publish on dynamicsaxnotes.blogspot.com once the domain is live. Replace `https://dasdynamics.dev` with the final address. Paste the HTML below in Blogger's HTML view.

Title: **Dynamics AX Notes has a new home**

```html
<p>I started this blog in January 2014, while working on Dynamics AX 2012. It was a notebook: a fix found at night, a snippet I didn't want to lose, a workaround worth sharing. Ten years and 64 posts later, AX has become Dynamics 365 Finance &amp; Operations, my work has moved towards architecture, integrations and AI, and the notebook needed a new home.</p>

<p><b>The new home is <a href="https://dasdynamics.dev">dasdynamics.dev</a>.</b> D as Dynamics. D as Diego.</p>

<p>I didn't just copy the old posts. I re-read every one of them against today's D365FO:</p>
<ul>
  <li>each note carries a verdict: <i>still valid</i>, <i>changed</i>, <i>historical</i> or <i>to review</i>, with a link to Microsoft Learn when something works differently today;</li>
  <li>the original code and text are kept as they were, so nothing you bookmarked is lost;</li>
  <li>a few posts that no longer help anyone have been retired.</li>
</ul>

<p>You will also find there the articles I published on LinkedIn, on integrations with Azure API Management, Copilot in D365FO, X++ and the platform, and everything I write from now on.</p>

<p>This blog stays online, so old links keep working. Each post now has a short note at the top pointing to its new version.</p>

<p>Thank you to everyone who read, commented and linked these notes over the years. See you on the other side.</p>

<p>Diego</p>
```
